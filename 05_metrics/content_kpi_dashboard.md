# 콘텐츠 KPI 대시보드

목적: 매주 콘텐츠가 계정 성장에 도움이 되는지 쉽게 확인하기 위한 문서입니다.  
기준 계정 상태: 팔로워 24,470명, 최근 새 팔로우 56명, 언팔로우 367명, 순성장 -311명, 비팔로워 조회 비율 17%, 도달 계정 530명

## 보는 방법

- 숫자는 매주 같은 요일에 한 번만 정리합니다.
- 조회수보다 먼저 봐야 할 것은 언팔, 비팔로워 도달, 저장, 공유, 스토리 반응입니다.
- 좋은 콘텐츠는 단순히 많이 본 콘텐츠가 아니라 팔로워 이탈을 줄이고, 비팔로워에게 도달하고, 기존 팔로워를 다시 반응하게 만든 콘텐츠입니다.

## 2. Reel KPI

| Reel Title | Upload Date | Views | Non-Follower View % | Watch Completion | Saves | Shares | New Followers | Main Learning |

| 밥 먹었어? |  |  |  |  |  |  |  |  |
| 괜찮아 |  |  |  |  |  |  |  |  |
| 친구 표현 |  |  |  |  |  |  |  |  |

허간 설명:
- 릴은 조회수도 중요하지만, `Non-Follower View %`가 더 중요합니다.
- 비팔로워 조회 비율이 높으면 새로운 사람에게 도달하고 있다는 뜻입니다.
- 저장과 공유가 높으면 "다시 보고 싶다" 또는 "친구에게 알려주고 싶다"는 신호입니다.
- 릴을 본 뒤 팔로우가 늘었는지도 꼭 확인합니다.

## 3. Story KPI

| 괜찮아 퀴즈 |  |  |  |  |  |  |  |  |
| 자연스러운 한국어 A/B |  |  |  |  |  |  |  |  |

허간 설명:
- 스토리는 조회수보다 `Poll/Quiz Responses`와 `Replies`가 중요합니다.
- 기존 팔로워가 퀴즈를 누르거나 답장을 하면 계정에 다시 반응하고 있다는 뜻입니다.
- `Story Exit Rate`가 높으면 스토리가 너무 어렵거나 길었을 수 있습니다.
- 다음 주에는 반응이 좋았던 퀴즈 형식을 반복합니다.

- 학습자가 저장했다는 것은 나중에 다시 보고 싶다는 뜻입니다.
- `Shares`가 높으면 친구에게 알려주고 싶은 콘텐츠입니다.
- 댓글이 적어도 저장이 높으면 좋은 학습 콘텐츠일 수 있습니다.

## 주간 리뷰 순서

1. 언팔로우가 줄었는지 확인합니다.
2. 비팔로워 조회 비율과 도달 계정이 늘었는지 확인합니다.
3. 릴 중에서 저장과 공유가 높은 콘텐츠를 찾습니다.
4. 스토리 중에서 퀴즈 응답과 답장이 많은 콘텐츠를 찾습니다.
5. 캐러셀 중에서 저장이 높은 콘텐츠를 찾습니다.
6. 다음 주에 반복할 콘텐츠 2개와 고칠 콘텐츠 1개를 정합니다.
