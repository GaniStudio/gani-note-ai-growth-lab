# Phase 1 실행 루프

목적: 콘텐츠 아이디어를 만들고, AI 검수와 허간 승인을 거쳐 업로드한 뒤, KPI를 보고 다음 콘텐츠를 개선하는 반복 흐름입니다.  
대상: 한국어를 배우는 베트남 여성 18-34세  
Phase 1 핵심 목표: 팔로워 이탈 감소, 비팔로워 도달 증가, 기존 팔로워 재활성화

## 전체 흐름 한눈에 보기

1. 콘텐츠 아이디어 생성
2. AI 리뷰
3. Human Director 허간 검토
4. 인스타그램 업로드
5. KPI 기록
6. 주간 리뷰
7. 다음 주 콘텐츠 개선

허간 설명:
이 루프는 매주 반복하는 기본 운영 방식입니다. 완벽한 콘텐츠를 한 번에 만드는 것보다, 올리고 기록하고 개선하는 것이 더 중요합니다.

## 1. Content Idea Creation

아이디어를 만들 때는 먼저 지금 계정 문제와 연결합니다.

우선순위:
- 팔로워 이탈을 줄이는 쉬운 한국어 표현
- 비팔로워가 궁금해할 문화 차이
- 기존 팔로워가 다시 누르고 답할 수 있는 스토리 퀴즈

아이디어 작성 위치:
- `04_content_db/content_ideas.csv`

아이디어에 꼭 들어갈 것:
- 한국어 표현
- 베트남어 설명 방향
- 훅 문장
- 콘텐츠 형식: 릴, 스토리, 캐러셀
- 기대 감정: 호기심, 공감, 위로, 실용성

허간 설명:
아이디어는 멋진 말보다 "베트남 학습자가 진짜 헷갈릴 만한가?"가 중요합니다. 예: `밥 먹었어?`, `괜찮아`, 카톡 표현처럼 바로 쓸 수 있는 주제가 좋습니다.

## 2. AI Review Flow

AI 리뷰는 콘텐츠를 더 안전하고 자연스럽게 만들기 위한 과정입니다.

리뷰 순서:
1. Gemini Pro: 베트남 대상층 관점과 자연스러운 베트남어 표현 확인
2. Claude Max: 문서 구조, 설명 흐름, 학습자 친화성 검토
3. ChatGPT Pro: 전략 방향과 Phase 1 목표 적합성 확인
4. Codex: 최종 문서를 파일로 정리하고 CSV 기록 업데이트

리뷰 기준:
- 훅이 첫 2초 안에 강한가?
- 베트남어가 자연스러운가?
- 한국어 뉘앙스가 맞는가?
- 스토리와 피드가 연결되는가?
- CTA가 하나로 명확한가?

허간 설명:
AI 리뷰는 콘텐츠를 어렵게 만들기 위한 과정이 아닙니다. 오히려 더 짧고, 더 쉽고, 더 자연스럽게 만들기 위한 검수입니다.

## 3. Human Director Review

최종 업로드 전에는 허간이 반드시 확인합니다.

허간이 볼 것:
- 브랜드 톤이 Gani_note답게 따뜻한가?
- 베트남 학습자가 부담 없이 볼 수 있는가?
- 실제 한국어 사용 느낌이 맞는가?
- 지금 목표인 이탈 감소, 비팔로워 도달, 팔로워 재활성화 중 하나에 연결되는가?

검토 문서:
- `03_content_strategy/content_production_checklist.md`
- `03_content_strategy/gani_note_brand_voice.md`

승인 상태:
- Approved: 업로드 가능
- Needs Revision: 수정 후 다시 확인
- Hold: 지금은 올리지 않음

허간 설명:
AI가 만든 문서가 좋아 보여도 최종 감각은 사람이 봐야 합니다. 특히 브랜드의 따뜻함과 실제 업로드 타이밍은 허간 판단이 가장 중요합니다.

## 4. Upload Flow

업로드는 간단하게 운영합니다. 아직 복잡한 자동화는 하지 않습니다.

업로드 전:
- 훅 문장 확인
- 자막 크기 확인
- CTA 하나만 남기기
- 스토리 퀴즈 연결 준비

업로드 순서:
1. 낮에 스토리 퀴즈 업로드
2. 저녁에 릴 또는 캐러셀 업로드
3. 밤에 스토리 정답 공개
4. 다음 날 짧은 복습 스토리 업로드

추천 시간:
- 스토리 퀴즈: 12:30 KST
- 릴: 20:30 KST
- 캐러셀: 21:00 KST
- 스토리 정답: 22:30 KST

허간 설명:
스토리로 먼저 궁금증을 만들고, 피드에서 답을 주고, 다시 스토리로 복습시키는 흐름입니다. 이렇게 하면 기존 팔로워가 한 번 더 반응할 가능성이 높습니다.

## 5. KPI Tracking Flow

업로드 후 숫자는 정해진 파일에만 기록합니다.

기록 파일:
- 릴 실험: `05_metrics/reels_experiment_log.csv`
- 스토리 퀴즈: `04_content_db/story_quiz_log.csv`
- 전체 KPI: `05_metrics/content_kpi_dashboard.md`
- 주간 지표: `05_metrics/weekly_metrics_template.csv`

업로드 후 2시간에 볼 것:
- 조회수
- 좋아요
- 댓글
- 스토리 응답

업로드 후 24시간에 볼 것:
- 비팔로워 조회 비율
- 도달 계정
- 저장
- 공유
- 신규 팔로우
- 언팔로우 변화

허간 설명:
조회수만 보면 판단이 흔들릴 수 있습니다. Phase 1에서는 `언팔 감소`, `비팔로워 도달`, `저장/공유`, `스토리 반응`을 더 중요하게 봅니다.

## 6. Weekly Review Flow

주간 리뷰는 매주 같은 요일에 한 번 진행합니다.

리뷰 순서:
1. 이번 주 언팔로우가 줄었는지 확인합니다.
2. 비팔로워 조회 비율이 17%보다 올라갔는지 확인합니다.
3. 가장 저장이 많은 콘텐츠를 찾습니다.
4. 가장 공유가 많은 콘텐츠를 찾습니다.
5. 스토리 퀴즈 응답이 많은 주제를 찾습니다.
6. 다음 주에 반복할 콘텐츠 2개를 정합니다.
7. 수정할 콘텐츠 1개를 정합니다.

주간 리뷰 질문:
- 어떤 훅이 가장 반응이 좋았나?
- 어떤 주제에서 언팔이 적었나?
- 어떤 콘텐츠가 비팔로워에게 많이 도달했나?
- 기존 팔로워가 가장 많이 누른 스토리는 무엇인가?

허간 설명:
주간 리뷰의 목적은 잘한 콘텐츠를 찾는 것입니다. 반응이 나쁜 콘텐츠를 비난하기보다, 왜 약했는지 보고 다음 주에 한 가지만 고치면 됩니다.

## 7. Reels vs Story Strategy

### Reels

릴의 역할:
- 비팔로워 도달 증가
- 신규 팔로우 유도
- 저장과 공유 만들기

릴에 좋은 주제:
- 문화 오해
- 자연스러운 표현 vs 어색한 표현
- 카톡이나 친구 대화 표현
- 15초 안에 설명 가능한 표현

릴 기준:
- 첫 2초 훅이 강해야 합니다.
- 설명은 짧아야 합니다.
- 마지막에 저장하거나 공유할 이유가 있어야 합니다.

### Story

스토리의 역할:
- 기존 팔로워 재활성화
- 퀴즈, 투표, 답장 유도
- 피드 콘텐츠로 이동시키기

스토리에 좋은 주제:
- A/B 선택 퀴즈
- 쉬운 뜻 맞히기
- 전날 콘텐츠 복습
- 다음 주 주제 투표

스토리 기준:
- 질문은 짧아야 합니다.
- 선택지는 2-3개가 적당합니다.
- 정답보다 참여가 중요합니다.

허간 설명:
릴은 새로운 사람을 데려오는 역할이고, 스토리는 이미 있는 팔로워를 다시 깨우는 역할입니다. 둘을 따로 보지 말고, 스토리로 궁금증을 만들고 릴로 답을 주는 방식으로 연결하면 좋습니다.

## 8. AI Role Responsibilities

| 역할 | 책임 | 주로 보는 것 |
|---|---|---|
| ChatGPT Pro | 전략 총괄, 최종 방향 정리 | Phase 1 목표와 콘텐츠 방향 |
| Gemini Pro | 베트남 대상층, 시장 감각 검토 | 베트남어 자연스러움, 트렌드, 현지 반응 |
| Claude Max | 문서와 콘텐츠 품질 검수 | 설명 흐름, 구조, 학습자 친화성 |
| Codex | 파일 생성, CSV 정리, 실행 문서 관리 | 문서 저장, 체크리스트, KPI 기록 구조 |
| 허간 | 최종 승인, 업로드, 실제 감각 판단 | 브랜드 톤, 실제 업로드 가능성, 최종 결정 |

허간 설명:
AI는 각각 역할이 다릅니다. 하지만 최종 업로드 여부는 허간이 결정합니다. AI는 자료를 정리하고 제안하는 역할이고, 허간은 실제 계정의 방향을 결정하는 사람입니다.

## 매주 반복할 최소 루프

1. 아이디어 5개 작성
2. 릴 3개, 캐러셀 2개, 스토리 매일 준비
3. AI 리뷰 후 허간 승인
4. 업로드
5. 24시간 뒤 KPI 기록
6. 주말에 가장 반응 좋은 주제 2개 선택
7. 다음 주 콘텐츠에 반복 적용

최종 기준:
이번 주 콘텐츠가 팔로워를 덜 떠나게 하고, 새로운 사람에게 더 많이 닿고, 기존 팔로워를 다시 누르게 만들었는가?
