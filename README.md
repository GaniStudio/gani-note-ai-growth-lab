# Gani_note AI Growth Lab

이 저장소는 Gani_note의 AI 성장 실험 프로젝트입니다.

## 목적
- 인스타그램 계정 @gani_note의 팔로워 반응을 재활성화합니다.
- 18-34세 베트남 여성 대상 한국어 학습 콘텐츠를 만듭니다.
- 1단계 목표는 팔로워 수 성장, 비팔로워 도달률 회복, 콘텐츠 업로드 증가입니다.

## 현재 상태
- 현재 팔로워: 24,470
- 최근 30일 팔로우 증가: 56
- 최근 30일 언팔: 367
- 순변화: -311
- 비팔로워 조회 비율: 17%
- 도달 계정: 530
- 최근 30일 업로드 콘텐츠: 7

## 구조
- `00_project_charter/` - 프로젝트 개요
- `02_account_research/` - 계정과 외부 조사
- `03_content_strategy/` - 콘텐츠 전략 및 계획
- `04_content_db/` - 콘텐츠 아이디어와 로그
- `05_metrics/` - KPI와 주간 지표
- `08_ai_training_log/` - AI 학습 기록

## 사용법
1. 먼저 `README.md`와 `00_project_charter/PROJECT_BRIEF.md`를 읽으세요.
2. `03_content_strategy/`에서 콘텐츠 방향을 확인합니다.
3. `05_metrics/weekly_metrics_template.csv`에 성과를 기록하세요.

> 이 단계에서는 복잡한 코드를 작성하지 않고, 기획과 기록을 정리하는 것이 중요합니다.
